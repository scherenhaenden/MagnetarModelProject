# Agent Routing Protocol (Tier 1: Micro)

> Primary operational protocol for AI agents collaborating on this micro project.

---

## What to Read & What to Update
| Activity | Read | Update | Rule |
| :--- | :--- | :--- | :--- |
| **Pick Next Task** | `PLAN.md` (`ready`) | `PLAN.md` (`→ in_progress`) | Max 2 active tasks per agent. |
| **Write Code** | Task in `PLAN.md`, `RULES.md` | Source files | Atomic commits referencing task ID. |
| **Finish Task** | `PLAN.md` criteria | `PLAN.md` (`→ done`), `STATUS.md` | Update metrics in `STATUS.md`. |
