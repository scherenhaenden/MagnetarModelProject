# Ruleset (Tier 1: Micro)

## Core Rules
1. **Naming**: Branch `<type>/<description>`, Tasks `task-<num>`.
2. **States**: `planned`, `ready`, `in_progress`, `in_review`, `blocked`, `done`.
3. **WIP**: Maximum 2 concurrent `in_progress` tasks per contributor.
4. **Commits**: Reference task ID in commit message.
